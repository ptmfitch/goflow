# goflow

Oil & gas production hydraulics suite (**Multiflow / GoFlow**, ~2000, VB5/6).

## Museum replica (web)

A clickable Win95-style recreation lives in [`web/`](web/):

```bash
cd web
npm install
npm run dev
```

Open http://localhost:5173 — double-click GoFlow and walk the setup → Print / Graph path. Physics is canned (`Demosum2.flw` fixture); see [`web/README.md`](web/README.md).
